# TP15 — 1.5 mm test pad

Not a purchasable part: a 1.5 mm square of exposed copper. Carries
`has_part_removed`, so it never reaches the BOM. The part number `TP-1.5MM` is
our own designation, not a manufacturer's — atopile wants one, and this says
plainly that nothing is being ordered.

**Why square and not round.** The obvious choice, KiCad's
`TestPoint_Pad_D1.5mm`, draws its silkscreen as a single circle. atopile cannot
compute a bounding box from arcs or circles — the code paths are unimplemented
stubs — so a footprint whose silk is only a circle crashes the build with
`min() iterable argument is empty`. `TestPoint_Pad_1.5x1.5mm` draws its outline
with four lines and is otherwise identical in size.

**Why not called `TestPoint`.** That is the name of an atopile standard-library
type. A component of the same name resolves to the library one, which has a
`contact` rather than a `pad`, and the failure surfaces far from its cause.

**Footprint.** KiCad stock `TestPoint:TestPoint_Pad_1.5x1.5mm`, unmodified.
