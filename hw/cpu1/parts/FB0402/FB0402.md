600 Ω ±25 % at 100 MHz, 100 mA, 0.9 Ω DC resistance. Extended, stock 10,571,
$0.0063. Read from JLCPCB's component API on 2026-09-17.

**The part first reached for was wrong.** C76873 was remembered as a ferrite
bead; the API returned a TDK piezo buzzer. Every part code here was looked up
rather than recalled for that reason.

**What is not checked.** Its DC resistance drops VDDA below 3V3 by the ADCs'
current times 0.9 Ω. The datasheet pages read for this board do not state
VDDA's current, so the drop is not bounded by any check — it is expected to be
millivolts, and bring-up should measure it.

**Footprint.** KiCad stock `Inductor_SMD:L_0402_1005Metric`, unmodified.
