# TP15 — 1.5 mm test pad

| | |
|---|---|
| Component | `TEST_PAD` |
| Manufacturer | n/a — bare copper |
| Part number | `TP-1.5MM` |

| Footprint | `TestPoint_Pad_1.5x1.5mm` |

Not a purchasable part: a 1.5 mm square of exposed copper, with no supplier
code, so it never reaches the bill of materials. `TP-1.5MM` is this project's
own designation.

Used on cpu1 for BOOT0 (bridge it to 3V3 to enter ST's ROM bootloader), the
console's two lines (also the bootloader's USART3), 3V3 and ground.

**Footprint.** KiCad stock `TestPoint:TestPoint_Pad_1.5x1.5mm`, unmodified.
